# Generatore di Mandala

App HTML/Canvas a file singolo per disegnare mandala simmetrici: ogni tratto viene ripetuto a specchio attorno al centro dello schermo, con un numero di ripetizioni regolabile.

## Utilizzo

Apri [index.html](index.html) in un browser (nessuna build o server richiesti) e disegna con il mouse o il dito.

## Controlli

| Controllo | Effetto |
| --- | --- |
| Simmetria | Numero di ripetizioni radiali del disegno (2–32) |
| Pennello | Spessore del tratto (1–20) |
| Colore | Colore del tratto |
| Arcobaleno | Cicla automaticamente la tonalità del colore mentre disegni |
| Pulisci | Cancella il canvas |
| Salva PNG | Scarica il disegno corrente come immagine PNG |

## Compatibilità

Funziona in qualsiasi browser moderno desktop o mobile che supporti Canvas 2D e touch events.
